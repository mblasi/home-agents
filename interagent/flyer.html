Features

Todo lo que el sistema sabe hacer

🎙️

Wake word propio

Modelo ONNX entrenado con voz Daniela (es_AR). 90 samples positivos, 1320 negativos. Score 0.96 en producción. Corre en CPU, sin Porcupine ni servicios de terceros.

Live
🧠

LLM local, sin API key

qwen2.5:7b via Ollama. Entiende comandos ambiguos, maneja contexto multi-turno, genera respuestas en español rioplatense. Latencia warm ~3.5s.

Live
🌐

WhatsApp como canal

Texto y notas de voz desde WhatsApp hacia el mismo orquestador. Whitelist de números. STT con faster-whisper. Respuesta texto o audio (Piper).

Próximo
🔔

Alertas proactivas

Cualquier agente puede publicar alertas en una cola FIFO. El sistema las anuncia por voz cuando estás en modo listening. Primer caso: lluvia inminente.

Live
👥

Identificación de usuarios

Enrollment por voz, embeddings biométricos locales, cosine similarity <200ms. Roles (admin/familiar/niño/invitado) con RBAC. Los datos nunca salen del hogar.

Próximo
🔀

Coordinador LLM multi-agente

"¿Debería llevar paraguas y tengo algo agendado mañana?" — el coordinador descompone el request, lanza agentes en paralelo y sintetiza la respuesta.

Próximo
🗺️

Estado compartido cross-agente

El agente clima publica `weather.is_raining` en shared_state. El agente domótica lo lee para bajar persianas sin que el usuario lo pida.

Live
📊

Dashboard en terminal

Panel zellij con wake word score animado, historial de comandos, latencias STT/LLM, agente activo. Métricas en tiempo real via /tmp/capitan/*.json.

Live
🔒

Privacidad total — ningún dato sale de tu red local

STT, LLM, TTS y todos los agentes corren en CPU, dentro de tu LAN. HAOS solo recibe órdenes via REST. Sin tokens de terceros, sin telemetría, sin cloud. Tus datos de inversiones, agenda y biométricos nunca abandonan el hogar.

Visión · Interagent Network

Internet es una red de redes.
Interagent es una red de redes de agentes.

Cada hogar o empresa corre su nodo. Los nodos publican y consumen servicios entre sí, formando un ecosistema distribuido con billing y reputación incorporados.

🏠

Nodo (local)

Orquestador FastAPI + agentes especializados. Agent SDK con keypair único. Publica y consume servicios de la registry. Metering agent para billing.

Visión
🗄️

Registry (cloud)

Catálogo de servicios con búsqueda, tags y schemas. Auth via keypair. Metering y billing mensual. Gateway para llamadas pagas.

Visión
⭐

Community layer

Stars por uso real, joins, maturity score. Sistema de reportes y auto-ban. Llamadas free directo nodo-a-nodo con rate limiting en el SDK.
